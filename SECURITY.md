# Política de segurança

Encontrou uma vulnerabilidade no FalaAí? Obrigado por ajudar a proteger quem usa o app.

- **Não abra issue pública.** Escreva para **<seguranca@falaai.com.br>**.
- Inclua passos para reproduzir, impacto esperado e versão afetada.
- Respondemos em até 3 dias úteis e combinamos uma data de divulgação coordenada (padrão: 90 dias).
- Um programa de bug bounty será aberto junto com o beta público.

Escopo prioritário: `falaai-core` (integração com a libsignal), armazenamento local, autenticação de dispositivos, entrega de mensagens e qualquer vazamento de metadados.
